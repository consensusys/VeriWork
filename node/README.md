# veriwork (Python reference node)

Python library of VeriWork: PoUW scoring, PoAW committee election,
multi-layer staking and dynamic slashing, the adaptive work controller,
commit-reveal sequencing, batching, prover backends (`SnarkJSProver`,
insecure `MockProver`), the Bancor credit market and `LocalL2`, the
in-process L2 used by the FlexFactory simulator and agents.  See the repository README for the full picture.

    pip install -e "node[dev]"      # from the repository root
